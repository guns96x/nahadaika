# Спільні чати: налаштування Firebase

Спільні чати працюють лише у варіанті `github` і лише коли налаштовано проєкт Firebase. Без налаштувань пункт «Поділитися з рідними» не з'являється, а решта застосунку працює як раніше.

## Що синхронізується

- Текстові нагадування: текст, час, повтор, будильник, «Готово», видалення.
- Обговорення під нагадуваннями з іменем автора.
- Голосові, кружечки й фото поки лишаються лише на телефоні автора.

Будильник ставить кожен телефон сам. Старі нагадування з історії чату в нового учасника не дзвонять. Повторюване нагадування переходить на найближчий раз. Коли застосунок закрито, нове підтягується раз на пів години, а коли відкрито — одразу.

## Кроки (один раз)

1. [console.firebase.google.com](https://console.firebase.google.com) → створити проєкт (Google Analytics не потрібен).
2. **Build → Authentication → Sign-in method** → увімкнути **Anonymous**.
3. **Build → Firestore Database** → Create database (режим production, регіон `eur3` або найближчий).
4. **Firestore → Rules** → вставити вміст [`firebase/firestore.rules`](../firebase/firestore.rules) → Publish.
5. **Project settings → General → Your apps** → додати Android-застосунок `ua.nahadaika`. Файл `google-services.json` не потрібен: з нього беруться три значення.
6. У `local.properties` (не комітиться) дописати:

   ```properties
   firebase.apiKey=AIza...            # "current_key" з google-services.json
   firebase.appId=1:1234567890:android:abc...   # "mobilesdk_app_id"
   firebase.projectId=nahadaika-xxxx  # "project_id"
   ```

   Для CI замість цього — секрети `FIREBASE_API_KEY`, `FIREBASE_APP_ID`, `FIREBASE_PROJECT_ID`.

7. Зібрати `./gradlew assembleGithubRelease`.

## Як користуватися

- Довге натискання на чат у списку (☰) → «Поділитися з рідними». Застосунок спитає ім'я, яке бачитимуть інші, і покаже код запрошення та кнопку «Надіслати».
- Учасник відкриває посилання `nahadaika://join/КОД` або у вікні «Новий чат» натискає «Маю код».
- Видалити спільний чат у себе означає вийти з нього. В інших учасників він лишається.

## Безкоштовний план (Spark)

Firestore дає 50 000 читань і 20 000 записів на добу. Сім'я з кількох людей їх не наблизиться. Підписка на сімейні чати (див. ROADMAP, «Монетизація») знадобиться, коли з'являться медіа у сховищі.
