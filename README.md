# Нагадайка

Android-застосунок для нагадувань у форматі чату — як відкладені повідомлення в Telegram, тільки окремо й зручніше: текст, голосові, відеокружечки, фото.

## Можливості

- **Одразу до справи** — відкривається в останньому чаті з полем вводу. Чати-теми («Дім», «Робота», «Ліки»), таймлайн дня зі смужкою днів і лінією «зараз».
- **Скажи — і готово** (🗣): «нагадай завтра о 9 купити хліб», «через пів години вимкнути плиту», «через 10 секунд», «постав таймер на 15 хвилин», «розбуди мене о 6:30», «щопонеділка о 10 планірка», «в обід», «після роботи», «на вихідних», «без десяти дев'ять», «за тиждень», «наприкінці місяця», «на наступному тижні в середу», «через дві з половиною години»… Розуміє числа словами, суржик і російські фрази. Слухає прямо в полі вводу, без вікна Google.
- **Голосове чи відео з часом усередині** — записали «завтра о 9 …», і нагадування ставиться саме. Розпізнавання у фоні системним сервісом або офлайн-пакетом Vosk (українська, завантажується в налаштуваннях).
- **Кнопка запису, як у Telegram**: тап — 🎤/📹, утримання — запис, угору — 🔒, уліво — скасувати. Відео — круглі кружечки, грають прямо на таймлайні.
- **Вибір часу барабанами**: «Через» (як таймер Samsung) і «Коли» (як «Надіслати пізніше» в Telegram), повтори щодня/щотижня/щомісяця/щороку.
- **Будильник**: гучна мелодія до вимкнення, екран поверх блокування, «Вимкнути» / «Ще 5 хв».
- **Сповіщення** з «+N хв», «+1 год», «Готово», «▶ Слухати»; фото й кадр відео прямо в сповіщенні. Точні будильники, відновлення після перезавантаження.
- **Оновлення із застосунку**: «Налаштування → Оновлення → Перевірити», фонова перевірка раз на пів дня. Завантажується лише патч від встановленої версії (≈2 МБ замість 20 МБ).
- **Пошук і архів**: 🔍 у шапці чату та списку чатів — пошук за словом по всіх чатах (і за видом: «голосове», «відео»), фільтри «Заплановані» / «Виконані», очищення виконаних.
- **Віджет і плитка**: віджет на головному екрані показує найближче нагадування й має кнопки «сказати», «голосове», «відео»; плитка «Нагадати голосом» у шторці.
- **Резервна копія**: «Налаштування → Резервна копія» зберігає чати, нагадування й записи одним ZIP-файлом; відновлення додає до наявного без дублів.
- **Налаштування**: тема (світла/темна/авто), мовний пакет, відкладання, типова година, режим запису й камера, стан дозволів.
- Усе зберігається тільки на телефоні, без акаунтів.

## Встановлення

Скачайте APK з [Releases](../../releases/latest), відкрийте на телефоні й дозвольте встановлення. Потрібен Android 8.0+. Далі оновлення — прямо із застосунку.

## Розробка на ПК

Потрібно: JDK 17, Android SDK (compileSdk 35). Шлях до SDK — у `local.properties` (`sdk.dir=…`) або змінна `ANDROID_HOME`.

```bash
./gradlew testDebugUnitTest   # тести (Robolectric) + знімки екранів у app/build/screenshots
./gradlew lintDebug
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

### Підпис

Щоб нова версія ставала поверх старої без втрати даних, усі збірки підписуються одним ключем. Ключа в репозиторії немає — задайте змінні середовища:

| Змінна | Значення |
| --- | --- |
| `NAHADAIKA_KEYSTORE` | шлях до `.jks` |
| `NAHADAIKA_KEYSTORE_PASSWORD` | пароль (однаковий для сховища й ключа) |
| `NAHADAIKA_KEY_ALIAS` | необов'язково, типово `nahadaika` |

Без ключа APK підпишеться debug-ключем (поверх релізної версії не встановиться).

### Випуск нової версії

1. Підніміть `versionCode` і `versionName` в `app/build.gradle.kts`, опишіть зміни в `whatsnew.txt`.
2. Push у `main`. GitHub Actions збере APK, створить реліз `v<версія>` з APK, патчем від попередньої версії та `update.json` (`tools/release.sh`, `tools/make_update.py`).
3. Для цього в *Settings → Secrets and variables → Actions* мають бути `NAHADAIKA_KEYSTORE_BASE64` (`.jks` у base64) і `NAHADAIKA_KEYSTORE_PASSWORD`.

## Структура

```
app/src/main/java/ua/nahadaika/
  VoiceParser.kt   розбір фраз із часом (українська, суржик, російська)
  Timeline.kt      що припадає на день таймлайну
  data/            Room: чати, нагадування; Repo — доставка, повтори, відкладання
  alarm/           AlarmManager, сповіщення, екран будильника
  media/           запис голосу/відео, відтворення, розпізнавання (Speech, OfflineSpeech/Vosk)
  update/          оновлення з GitHub Releases, накладання патча (BsPatch), фонова перевірка
  widget/          віджет головного екрана й плитка шторки
  Search.kt        пошук по нагадуваннях; data/Backup.kt — резервна копія (ZIP)
  ui/              Compose: чат (ChatScreen, ChatHeader, ChatComposer), список чатів, пошук, налаштування, вибір часу, тема Glass
tools/             випуск релізу й патчів
```
