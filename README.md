# Нагадайка

Android-застосунок для нагадувань у форматі чату — як відкладені повідомлення в Telegram, тільки окремо і зручніше.

## Можливості

- **Тема: темна, світла або авто** (як у системі) — кнопка ☾/☀ угорі праворуч; вибір запам'ятовується.
- **Дизайн Glassmorphism** (у темній темі): майже чорний фон з глибоким сяйвом, тонке скло з розмиттям того, що під ним (Android 12+), шрифт Inter, світлі кнопки головних дій; зверху чату — велика картка найближчого нагадування з живим відліком, у кожного нагадування — скільки лишилось.
- **Таймлайн дня** (як у Structured): угорі смужка днів із кольоровими крапками там, де є нагадування; нижче — день по годинах: час, кружок за типом (текст / голосове / відео / фото), червона лінія «зараз». Минуле показується виконаним ✓, повторювані — на кожному своєму дні. Якщо обрано інший день, нове нагадування пропонується саме на нього.
- **Одразу до справи**: застосунок відкривається в останньому чаті з полем вводу — можна писати, записувати чи говорити без зайвих кроків. Список чатів — кнопка ☰.
- **Скажіть — і готово**: кнопка 🗣 у полі вводу. «Нагадай завтра о 9 купити хліб», «через 2 години подзвонити мамі», «щопонеділка о 10 планірка», «25 жовтня о 12 день народження», «о пів на восьму вечора кіно» — час і повтор розпізнаються, решта стає текстом нагадування. Якщо час не зрозумілий — відкриється вибір часу.
- **Кнопка запису, як у Telegram**: тап — перемкнути 🎤 голосове ↔ 📹 відео (режим запам'ятовується); утримання — запис, відпустили — обираєте час; утримуючи, потягніть угору до 🔒 — запис без рук (✓ — готово); потягніть уліво — скасувати. Відео пишеться «кружечком» прямо в чаті, ⟲ — інша камера. Відео показується круглим «кружечком» (як у Telegram) і відтворюється прямо на таймлайні (тап — пауза, прогрес — кільцем по краю), без окремого вікна.
- **Ярлики на головному екрані** (утримайте іконку): «Відео», «Голосове», «Сказати».
- **Чати-теми** («Дім», «Робота», «Ліки»…) — кожен зі своїм списком нагадувань.
- **Будь-який формат**: текст, відео, голосове, фото з камери чи галереї, медіа з підписом. Після запису можна просто сказати «завтра о 9» у вікні вибору часу.
- **Вибір часу барабанами** з двома вкладками зі спільним часом: **«Через»** — години : хвилини : секунди, як таймер Samsung (кнопки 5/10/15/30 хв, 1–2 год); **«Коли»** — день | година | хвилина, як «Надіслати пізніше» в Telegram (кнопки «Завтра 09:00» тощо). Останні вкладка й значення таймера запам'ятовуються.
- **Повтори**: щодня, щотижня, щомісяця, щороку (31-ше число не «з'їжджає», перехід на зимовий/літній час враховано).
- **Сповіщення** з кнопками «+10 хв», «+1 год», «Готово»; для голосових — «▶ Слухати». Фото й кадр з відео показуються прямо в сповіщенні.
- **Надійність**: точні будильники, відновлення після перезавантаження/зміни часу, доставка пропущених нагадувань. Банери підкажуть, якщо сповіщення чи фонова робота заборонені.
- **Історія**: минулі дні на таймлайні показують, що вже надійшло; будь-яке можна «нагадати ще раз».
- Усе зберігається тільки на телефоні, без акаунтів. Розпізнавання мовлення використовує системний сервіс Google.

## Встановлення

1. Скачайте `app-release.apk` (з артефакту GitHub Actions «nahadaika-apk» або з повідомлення в чаті).
2. Відкрийте файл на телефоні й дозвольте встановлення з цього джерела.
3. При першому запуску дозвольте сповіщення. На Xiaomi/Samsung/Huawei натисніть «Дозволити» в банері про фонову роботу.

Потрібен Android 8.0 або новіший.

## Збірка

```bash
cd reminder-app
./gradlew testDebugUnitTest   # тести логіки + знімки екранів у app/build/screenshots
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

### Підпис

Щоб нова версія встановлювалась **поверх старої без втрати нагадувань**, усі збірки мають бути підписані одним ключем.
Ключ не зберігається в репозиторії (він публічний). Задайте його через змінні середовища:

| Змінна | Значення |
| --- | --- |
| `NAHADAIKA_KEYSTORE` | шлях до `.jks` |
| `NAHADAIKA_KEYSTORE_PASSWORD` | пароль (однаковий для сховища і ключа) |
| `NAHADAIKA_KEY_ALIAS` | необов'язково, типово `nahadaika` |

Для GitHub Actions додайте в *Settings → Secrets and variables → Actions*:
`NAHADAIKA_KEYSTORE_BASE64` (вміст `.jks` у base64) і `NAHADAIKA_KEYSTORE_PASSWORD`.
Без ключа APK підпишеться тимчасовим debug-ключем.

## Структура

```
app/src/main/java/ua/nahadaika/
  VoiceParser.kt  розбір голосових команд українською
  data/    Room: чати, нагадування; Repo — логіка доставки, повторів, відкладання
  alarm/   AlarmManager, BroadcastReceiver-и, сповіщення
  media/   запис голосу, програвач, імпорт фото/відео
  ui/      Jetpack Compose: чат, запис відео (CameraX), вибір часу, список чатів
  ui/theme/Glass.kt  скляні компоненти, фон, розмиття (Haze)
```
