# Нагадайка

Android-застосунок для нагадувань у форматі чату — як відкладені повідомлення в Telegram, тільки окремо і зручніше.

## Можливості

- **Чати-теми** («Дім», «Робота», «Ліки»…) — кожен зі своїм списком нагадувань.
- **Будь-який формат**: текст, голосове (запис одним дотиком), фото чи відео з камери або галереї, медіа з підписом.
- **Швидкий вибір часу**: «через 30 хв», «завтра о 09:00», «через тиждень»… або своя дата й час.
- **Повтори**: щодня, щотижня, щомісяця, щороку (31-ше число не «з'їжджає», перехід на зимовий/літній час враховано).
- **Сповіщення** з кнопками «+10 хв», «+1 год», «Готово»; для голосових — «▶ Слухати» (відкриває чат і одразу програє запис). Фото й кадр з відео показуються прямо в сповіщенні.
- **Надійність**: точні будильники (`setExactAndAllowWhileIdle`), відновлення після перезавантаження/зміни часу, доставка пропущених нагадувань, якщо телефон був вимкнений. Банери підкажуть, якщо сповіщення чи фонова робота заборонені.
- **Історія**: вкладка з нагадуваннями, які вже надійшли; будь-яке можна «нагадати ще раз».
- Усе зберігається тільки на телефоні, без інтернету й акаунтів.

## Встановлення

1. Скачайте `app-release.apk` (з артефакту GitHub Actions «nahadaika-apk» або з повідомлення в чаті).
2. Відкрийте файл на телефоні й дозвольте встановлення з цього джерела.
3. При першому запуску дозвольте сповіщення. На Xiaomi/Samsung/Huawei натисніть «Дозволити» в банері про фонову роботу.

Потрібен Android 8.0 або новіший.

## Збірка

```bash
cd reminder-app
./gradlew testDebugUnitTest   # тести логіки + знімки екранів у app/build/screenshots
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

### Підпис

Щоб нова версія встановлювалась **поверх старої без втрати нагадувань**, усі збірки мають бути підписані одним ключем.
Ключ не зберігається в репозиторії (він публічний). Задайте його через змінні середовища:

| Змінна | Значення |
| --- | --- |
| `NAHADAIKA_KEYSTORE` | шлях до `.jks` |
| `NAHADAIKA_KEYSTORE_PASSWORD` | пароль (однаковий для сховища і ключа) |
| `NAHADAIKA_KEY_ALIAS` | необов'язково, типово `nahadaika` |

Для GitHub Actions додайте в *Settings → Secrets and variables → Actions*:
`NAHADAIKA_KEYSTORE_BASE64` (вміст `.jks` у base64) і `NAHADAIKA_KEYSTORE_PASSWORD`.
Без ключа APK підпишеться тимчасовим debug-ключем.

## Структура

```
app/src/main/java/ua/nahadaika/
  data/    Room: чати, нагадування; Repo — логіка доставки, повторів, відкладання
  alarm/   AlarmManager, BroadcastReceiver-и, сповіщення
  media/   запис голосу, програвач, імпорт фото/відео
  ui/      Jetpack Compose: список чатів, чат, вибір часу
```
